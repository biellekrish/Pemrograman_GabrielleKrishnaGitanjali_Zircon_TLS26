# Tugas Pemrograman Dasar TLS 2026

Repository ini berisi penyelesaian Tugas Pemrograman Dasar TLS 2026 yang terdiri dari Fase 1 (Logika, Pseudocode, dan Flowchart) serta Fase 2 (Implementasi Kode C++).

## Identitas
- **Nama Lengkap: Gabrielle Krishna Gitanjali** 
- **Kelompok: Zircon** 

---

## Isi Repository

1. **`Fase 1_Gabrielle Krishna Gitanjali_Zircon.pdf`**  
   Dokumen Fase 1 yang berisi penjelasan logika, pseudocode, dan flowchart untuk Problem 1 (The Last Astronaut) dan Problem 2 (Alien-In-The-Middle).

2. **`Problem1_TheLastAstronaut.cpp`**  
   Program C++ untuk menyelesaikan **Problem 1: The Last Astronaut** (Simulasi eliminasi astronot melingkar dengan pembaruan nilai K dinamis).

3. **`Problem2_AlienInTheMiddle.cpp`**  
   Program C++ untuk menyelesaikan **Problem 2: Alien-In-The-Middle** (Sandi rahasia enkripsi pergeseran huruf berdasarkan alfabet sebelumnya).

---

## Ketentuan Teknis
- Program C++ dibuat tanpa library pihak ketiga (hanya menggunakan `<iostream>`).
- Menggunakan fungsi buatan sendiri (*user-defined functions*).
